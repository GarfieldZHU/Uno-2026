# Reference UNO card visuals

These SVG resources are crops of the 6,212 × 3,729 JPEG sprite sheet `0.jpg` from the public repository [yunwei37/UNO-game-oop](https://github.com/yunwei37/UNO-game-oop), path `src/UNO2D/0.jpg` (retrieved 2026-08-13). The source repository is MIT licensed (see its `LICENSE`), but the card artwork itself is third-party UNO-style artwork and is **not claimed to be official Mattel artwork**. Treat these files as reference/prototype assets and verify redistribution rights before production use.

`0.jpg` is retained as the provenance source. Each `.svg` uses an SVG viewport and an `<image>` crop into that source, preserving the original raster resolution without tracing or altering the artwork. Generated set: 52 colored cards (red/green/yellow/blue zero, draw-two, reverse, 0–9), plus `card-back.svg`, `wild-draw-four.svg`, and `wild.svg`.
