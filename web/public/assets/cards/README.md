# Uno-2026 card artwork

These SVGs are original project artwork: they use the familiar four-color UNO
game vocabulary (red, yellow, green, blue; number and action cards) without
copying Mattel's proprietary card illustrations or logo. `card-symbols.svg`
contains reusable vector symbols for Skip, Reverse, +2, Wild, and +4. The
public repository [yunwei37/UNO-game-oop](https://github.com/yunwei37/UNO-game-oop)
was consulted only for its documented rules and card categories; its MIT
license applies to that repository's source, not to third-party UNO branding.
