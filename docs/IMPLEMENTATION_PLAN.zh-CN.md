# 实现计划

[English](IMPLEMENTATION_PLAN.md) | 中文

1. 定义确定性的 Rust 领域层：108 张牌、合法出牌检查、功能牌效果、摸牌堆回收、UNO 喊牌与罚牌、胜者检测和 JSON 快照。
2. 在统一决策接口后提供四个确定性的 AI 档位。
3. 通过 `wasm-bindgen` 导出领域层，把生成绑定限制在 Web 构建边界内，并保留原生测试作为源码契约。
4. 构建 React 牌桌外壳：模式启动器、HUD、对手、卡牌组件、选色器、键盘安全操作和响应式手牌。
5. 增加 Rust 房间服务、CI、Vercel 配置和浏览器冒烟测试。
6. 运行 Rust、TypeScript、生产构建和浏览器检查；确认请求的 GitHub 所有者可写后再提交并发布。
