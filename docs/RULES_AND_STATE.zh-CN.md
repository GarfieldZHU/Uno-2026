# 规则与状态

[English](RULES_AND_STATE.md) | 中文 · [架构说明](ARCHITECTURE.zh-CN.md)

## 牌堆

当前实现采用经典 108 张牌：

- 红、黄、绿、蓝四种颜色各一张 0；
- 每种颜色各有两张 1–9；
- 每种颜色各有两张 `Skip`、两张 `Reverse`、两张 `DrawTwo`；
- 另有四张 `Wild` 和四张 `WildDrawFour`。

离线牌桌支持 3–8 个席位。0 号席位是人类玩家（`You`），其余席位使用选定的 AI 档位；
默认四人。每个席位发七张牌。首张弃牌从剩余数字牌中选取，因此牌桌以一个有效颜色开始，
不会在开局立即触发功能牌效果。摸牌堆耗尽时，会保留最上方弃牌，把其余弃牌洗回摸牌堆。
`GameState::new` 仍是四人兼容构造器，`new_with_player_count` 会把领域输入限制在 3–8。

每个 AI 的 1–30 秒停顿属于 React 调度设置，不属于 Rust 快照或规则。它只负责让 AI 回合
可读；真正的出牌选择和状态推进仍由 `ai_step` 在 Rust 中完成。

## 合法出牌

万能牌、匹配当前颜色的牌、或匹配弃牌牌型的牌都可以出。`WildDrawFour` 只有在玩家
没有匹配当前颜色的非万能牌时才合法。越权回合、游戏已结束、或正在等待 `+2/+4` 罚牌
时的命令，会返回 JSON 错误。

## 功能牌效果

| 牌 | 效果 |
| --- | --- |
| 数字牌 | 推进一名玩家 |
| Skip | 跳过下一名玩家 |
| Reverse | 反转方向；两人游戏时等价于跳过 |
| DrawTwo | 下一名玩家摸两张并消耗罚牌状态 |
| Wild | 选择新的当前颜色 |
| WildDrawFour | 选择颜色，下一名玩家摸四张 |

当前牌桌采用不叠加罚牌：面对 `+2` 或 `+4` 的玩家直接摸对应数量。UI 会把待处理数量
显示成连击风格徽章并播放强制摸牌动画，但这只是展示，不会改变权威的不叠加规则。未来如需
叠加，应增加显式规则集，而不是隐式改变当前行为。

## 摸牌

摸到一张可出的牌时，人类玩家仍停留在当前回合，可以选择打出或保留；摸到不可出的牌
则推进回合。摸掉待处理罚牌会消耗罚牌状态并推进回合。这一行为由
`GameState::draw_for_player` 定义，修改前应补充对应测试。

## UNO 喊牌

出牌后剩一张牌会创建 `uno_pending` 标记。玩家仍持有一张牌时必须调用 `call_uno`；
下一条命令结算标记时若未喊 UNO，则摸两张。AI 在剩一张牌后自动喊 UNO；人类界面提供
`CALL UNO` 按钮。

## 快照隐私

公开快照包含人类手牌和每位玩家的手牌数量，但不包含 AI 的具体牌面。这是 UI/数据契约，
不是对恶意客户端的安全边界；未来真正的联机权威服务必须把隐藏手牌保留在服务端。
