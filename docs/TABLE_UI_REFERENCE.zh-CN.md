## 2026 视觉刷新

主菜单、开局设置、抽屉和牌桌现在共用一套克制的材质语言：深绿色绒布、用于操作
的暖纸色/金色，以及表示实时状态的薄荷色。主菜单只保留一个最主要的“开始游戏”
操作，联机、设置和关于收进紧凑的次要按钮区；开局设置仍像一张牌桌入场券，不会
变成信息仪表盘。

牌桌占据最大的视觉空间。顶部信息栏默认收起，摸牌堆、弃牌堆和飞行动效所在的中央
区域保持清爽；手牌轨道成为一块高对比度的连续区域，并使用更大的 SVG 卡牌。当前
玩家和下一位出牌玩家通过颜色与浮层高度区分，避免常驻大段状态文字。窄屏时布局收为单列，
手牌仍可横向触达。

视觉参考来自用户提供的 Google Play UNO Offline 牌桌：玩家围绕牌桌分布，对手用卡背扇表示手牌，摸牌堆和弃牌堆共享中央区域，人类手牌沿近侧形成扇形。这里只参考构图和交互习惯；UNO-2026 使用自己生成和编写的资源。

交互规则：

1. 自己回合点击摸牌堆摸牌。
2. 点击弃牌堆打开按时间排序的已出牌历史。
3. 单击发光手牌会先提起，再次单击（或双击）确认出牌；也可以把牌拖到牌桌上
   进行明确出牌。万能牌会在牌面上方打开选色器。
4. 牌桌只保留高信号操作；设置和语言切换留在牌桌外层。
5. 联机大厅和牌桌右下角的 `⌁` 只在点击时导出脱敏网络诊断，不上传日志。

资源加载完成后会先播放约 3.8 秒从中央牌堆飞向各座位的发牌动画，再提示起始玩家并启用操作。出牌方向改为绑定实际座位的半透明 SVG 路径：每条路径连接当前方向上的相邻玩家，当前玩家到下一位出牌玩家的路径使用金色流动高亮，其余路径保持低调；悬停路径会提高对比度。原来的中央方向胶囊不再渲染。下一位标签明确写为“下一位出牌”，不再使用容易误解的“下家”。牌局结束时显示包含获胜者姓名的胜负结算层。动画由状态驱动（`deal`、`shuffle`、`draw`、`play`、结算），并遵守 `prefers-reduced-motion`。

当前玩家摸牌时，只有该玩家自己的客户端看到私有摸牌揭示：卡背从摸牌堆飞入，翻到已解析的 SVG 牌面后插入手牌，新牌保持约两秒高亮，方便定位。其他客户端只收到公开的手牌数量变化，不会看到别人的牌面。

网络诊断按钮旁的低调局内记录按钮会打开已观察到的快照时间线。它只记录公开状态
（不会写入其他玩家的隐藏手牌），可在本地逐条回放，并下载 JSON 供归档或复盘，
不会自动上传。
