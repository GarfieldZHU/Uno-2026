## 2026 视觉刷新

主菜单、开局设置、抽屉和牌桌现在共用一套克制的材质语言：深绿色绒布、用于操作
的暖纸色/金色，以及表示实时状态的薄荷色。主菜单只保留一个最主要的“开始游戏”
操作，联机、设置和关于收进紧凑的次要按钮区；开局设置仍像一张牌桌入场券，不会
变成信息仪表盘。

牌桌占据最大的视觉空间。顶部信息栏默认收起，摸牌堆、弃牌堆和飞行动效所在的中央
区域保持清爽；手牌轨道成为一块高对比度的连续区域，并使用更大的 SVG 卡牌。当前
玩家获得最强的金色环、抬升和“你的回合”处理，下一位出牌玩家只使用较弱的薄荷色标记，
从层级上明确主次。窄屏时布局收为单列，手牌仍可横向触达。手机和平板会按视口高度
重新分配空间：竖屏把紧凑手牌扇放在牌桌下方，横屏则缩小牌桌、席位、牌堆和卡牌，合并
为不产生页面滚动的一列；横屏隐藏绒布中重复的回合胶囊，保留标题中的回合信息。顶部
和底部活动席位会保留水平锚点，牌面直接使用源 SVG 自带的边缘，不再叠加第二层深色内框。

视觉参考来自用户提供的 Google Play UNO Offline 牌桌：玩家围绕牌桌分布，对手用卡背扇表示手牌，摸牌堆和弃牌堆共享中央区域，人类手牌沿近侧形成扇形。这里只参考构图和交互习惯；UNO-2026 使用自己生成和编写的资源。

交互规则：

1. 自己回合点击摸牌堆摸牌。
2. 点击弃牌堆打开按时间排序的已出牌历史。
3. 单击发光手牌会先提起，再次单击（或双击）确认出牌；也可以把牌拖到牌桌上
   进行明确出牌。万能牌会在牌面上方打开选色器。
4. 牌桌只保留高信号操作；设置和语言切换留在牌桌外层。
5. 联机大厅和牌桌右下角的 `⌁` 只在点击时导出脱敏网络诊断，不上传日志。

资源加载完成后会先播放约 3.8 秒的发牌动画：发牌源点实时测量实际摸牌堆，每个目标点实时测量实际对手牌扇或人类手牌槽，因此会随牌桌尺寸和 3–10 人排布正确落位。当前玩家的牌全程背面朝上飞入，手牌计数从 `0/N` 逐张增加，最后一张落定后才翻开对应 SVG 牌面；随后提示起始玩家并启用操作。出牌方向改为绑定实际座位的半透明 SVG 路径：每条路径连接当前方向上的相邻玩家，当前玩家到下一位出牌玩家的路径使用金色流动高亮，其余路径保持低调；悬停路径会提高对比度。原来的中央方向胶囊不再渲染。下一位标签明确写为“下一位出牌”，不再使用容易误解的“下家”。逆转和跳过牌会显示约 2.6 秒的顺序变化层，直接点名受影响玩家和新的下一位。`uno_pending_player` 指向人类时，喊 UNO 按钮会放大并变为高信号样式；喊牌后从头像位置显示约 3 秒的“UNO!”。插入式窗口中，犯规席位会出现 `CHALLENGE UNO`，揭发结算不占用下一位的倒计时。牌局结束后先显示胜负结算层，五秒后再显示“再来一局”和“退出”。牌桌右上角始终保留低调的退出按钮。动画由状态驱动（`deal`、`shuffle`、`draw`、`play`、逆转/跳过、UNO、结算），并遵守 `prefers-reduced-motion`。

方向路径与玩家席位使用同一个解析器：3–10 人分别采用对应的环形排布，9/10 人在靠近人类席位的位置使用浅层下角席位。SVG 始终按实际席位数量生成一段有方向的连接；端点会收进玩家卡片之间的空隙，曲线向牌桌外缘弯曲，三人横向连接会走上弧线，避免穿过中央牌堆。每条曲线会在几何中点拆分并放置唯一箭头，箭头位于玩家之间的开放区域，连线本身也会在头像前留出安全距离。当前玩家到下一位玩家的箭头由实际快照顺序决定，即使玩家 ID 不连续也不会错位，不再叠加固定八人模板。

当前玩家摸牌时，只有该玩家自己的客户端看到私有摸牌揭示：卡背从摸牌堆飞入，翻到已解析的 SVG 牌面后插入手牌，新牌保持约两秒高亮，方便定位。其他客户端只收到公开的手牌数量变化，不会看到别人的牌面。

网络诊断按钮旁的低调局内记录按钮会打开已观察到的快照时间线。它只记录公开状态
（不会写入其他玩家的隐藏手牌），可在本地逐条回放，并下载 JSON 供归档或复盘，
不会自动上传。
