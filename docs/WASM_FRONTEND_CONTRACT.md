# WASM / frontend contract

[中文](WASM_FRONTEND_CONTRACT.zh-CN.md) · [Architecture](ARCHITECTURE.md)

## Loading boundary

`web/src/wasm.ts` dynamically imports `/wasm/uno_core.js`. The file is generated by
`wasm-pack build crates/uno-core --target web --out-dir ../../web/public/wasm
--release`. `scripts/build-wasm.mjs` uses an existing committed artifact unless
`UNO_REBUILD_WASM=1` is set; a missing artifact is still a hard build error.

The generated directory is a release artifact, not a second source tree. Change
Rust first, rebuild WASM, then run the TypeScript and browser checks.

## Exported class

```text
new UnoGame(seed: number, profile: string)
static new_with_config(seed: number, profile: string, player_count: number)
snapshot(): string
play_card(card_id: number, chosen_color: string): string
draw(): string
call_uno(): string
ai_step(): string
restart(seed: number): string
```

`profile` accepts `garfield1993-ai-simple`, `garfield1993-ai-hard`,
`uno-2026-ai-easy`, or `uno-2026-ai-strategist`. An unknown profile currently
defaults to `garfield1993-ai-simple` in the Rust constructor.

`new_with_config` bounds `player_count` to 3–8 and creates one human seat plus
the remaining AI seats. The old two-argument constructor still creates four
seats for compatibility. React's per-seat AI pause values are intentionally not
sent through this ABI; they are UI scheduling values around `ai_step`.

## JSON shape

Normal commands return a `Snapshot`. Rejected commands return:

```json
{
  "ok": false,
  "error": "card-not-playable",
  "snapshot": { "...": "current state" }
}
```

The snapshot contains `players`, `current_player`, `direction`, `active_color`,
`top_card`, draw/discard counts, `pending_draw`, `status`, `winner`, `turn_number`,
`message`, `last_action`, and `ai_profile`. Human `players[0].hand` contains cards;
AI hand arrays are empty while `hand_count` remains visible.

## Error handling

The UI should display the returned `error` and keep the returned snapshot. It should
not retry a rejected command by mutating local state. A module load failure is a
startup error and should be visible as a retryable table-unavailable state.

## ABI changes

When changing an exported method or snapshot field:

1. update Rust native tests;
2. rebuild `web/public/wasm`;
3. update `web/src/types.ts` and this document in both languages;
4. run the production build and Playwright smoke test;
5. add a migration note if older saved snapshots will exist.
