# 联机网络诊断

[English](NETWORK_DIAGNOSTICS.md) | 中文

UNO-2026 的联机大厅和牌桌右下角都有一个低调的 `⌁` 按钮。点击后浏览器会下载
`uno-2026-network-<时间>.json`，供维护者分析网络环境和性能瓶颈。

## 记录内容

- WebSocket：连接尝试、握手耗时、打开/关闭、关闭码、异常、重连次数和退避时长。
- 消息流：消息类型、消息数量、消息字节数，以及是否包含房间快照；不会保存 JSON 消息正文。
- REST：请求方法、脱敏路由、HTTP 状态、耗时、响应大小和可见的 `x-vercel-id`/`server` 边缘标记。
- 浏览器网络能力：`navigator.onLine`、`effectiveType`、连接类型、估算 RTT/下行速率、Save-Data、页面可见性、视口和设备像素比。
- 页面拓扑线索：页面/API/WebSocket 的公开 origin、同源或独立服务路由、导航 DNS/TCP/TLS/请求/响应时序。

浏览器不会提供可可靠使用的本地路由表、Wi-Fi SSID、局域网设备或公网 IP；因此日志不会伪造这些信息。公开 origin 和可见边缘标记足以帮助区分 Vercel 静态页、反向代理和 Rust 服务之间的瓶颈。

## 脱敏边界

导出前会移除或不采集：

- 房间码、玩家 token、认证 header、昵称、手牌、牌堆和完整快照；
- 请求/响应正文、URL query 中的 `token`/`player_token`；
- 服务器密码、部署密钥及任何环境变量。

用户点击按钮后才会生成下载文件；应用不会把日志自动上传到 UNO-2026 或第三方服务。提交日志前仍建议快速查看 JSON，确认没有浏览器扩展或代理注入的额外敏感字段。

## 如何提交

1. 在出现卡顿、频繁降级或断线时点击 `⌁` 导出。
2. 保留导出文件原名，并注明发生时间、浏览器/设备、使用的网络类型以及“联机大厅”或“牌桌”。
3. 将 JSON 作为 issue/私下附件提交，不要粘贴到公开聊天中暴露不必要的环境信息。

日志是诊断辅助，不是确定性牌局回放；规则和牌局状态仍以 Rust 服务快照为准。
