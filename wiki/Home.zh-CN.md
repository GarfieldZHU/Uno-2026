# UNO 2026

Rust 规则、WebAssembly 离线运行时、React 牌桌。

UNO 2026 是一个确定性的浏览器 UNO 游戏，拥有可原生测试的 Rust 核心和响应式
TypeScript HUD。当前支持离线牌桌和模块化 Rust REST + WebSocket 房间：四位房间码、15 分钟
有效期、混合人类/AI 席位、房主开始/关闭、断线重连和按 token 隔离手牌；牌局中离席会由 AI
接管原席位（房主离席时权限转移给剩余人类），服务仍是内存演示。

主菜单只提供开始游戏、设置和关于。设置抽屉支持 3–8 个离线席位（默认四人），由一名人类和 AI
席位组成；每个 AI 都可单独设置 1–30 秒停顿（默认三秒）。牌桌使用 SVG 卡牌，进入牌桌时先播放约 3.8 秒的发牌动画并提示起始玩家；出牌方向沿玩家席位用半透明连接箭头表示，悬停时增强高亮；牌局结束会显示获胜/失败结算层，并可按需打开按时间排序的弃牌历史。联机流程允许混合多名人类和 AI，等待阶段房主离开会关闭房间，
开局后任何离席都会由 AI 接管原席位（房主权限转移给剩余人类）；
人类倒计时结束会自动合法出牌或摸牌；公开使用前需要配置 Rust 服务地址并放在 TLS 后。

联机弹窗默认是“加入房间”，只显示昵称和房间码；“创建房间”是独立的房主模式，进入后才显示总席位、AI 数量和倒计时设置，房间码由服务端生成。
主菜单底部也保留一个低调的 `alohayo.me` 项目主页链接。

界面默认使用中文；`EN` 按钮可以在不重启牌局的情况下，将菜单、设置抽屉和游戏 HUD 切换为英文。

## 启动

```bash
npm install
npm run dev
```
